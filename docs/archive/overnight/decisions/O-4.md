# O4 — Source type when copying your own problem

Status: **Open**. Not decided by this document.

## Current state

- **Runbook §6 (Open), quoted:** "The spec says OWN → LICENSED_USE citing the original author, with no exception for copying your own problem. The mock does the same. It probably should stay OWN."
- **Spec 2.0.0 (`copyProblem`):** "Source: OWN → LICENSED_USE citing the original author; LICENSED_USE and FREE_USE keep their type and citation; the licence is always inherited." Same rule applies to `copyFromId` in `addSetChild` ("usual copy rules").
- **Runbook §6 (Decided), related:** "Copies are new records. Only global tags and chapters are copied, unless the caller owns the original." So the spec already makes an owner exception for tags/chapters, but not for the source.
- **Mock:** `domain/copy-rules.ts:10-15` `sourceForCopy` turns OWN into LICENSED_USE with `Převzato od: <author>` for every copy, including your own. The code says so: `copy-rules.ts:7` "TODO decide: copying your own problem currently also becomes LICENSED_USE citing yourself".
- **Effect today:** Jan copies his own "Obsah kruhu" → the copy says "LICENSED_USE, Převzato od: Jan Novák", licence CC BY 4.0. A private OWN problem without licence copied by its owner becomes LICENSED_USE with **no** licence (licence is inherited: null).
- **Tests:** `actions/copy.e2e-spec.ts` deliberately does not assert `source.type`/citation on own copies.

## Options

### A. Keep the spec as is (own copies become LICENSED_USE citing yourself)
- **Pros:** one rule, no branch; the copy records where it came from; nothing to change anywhere.
- **Cons:** semantically odd ("licensed use" of your own work); the citation names yourself; a LICENSED_USE copy with a null licence is an odd state (LICENSED_USE normally implies a licence); may confuse the publish flow (a licence can still be chosen at publish, because none is set).
- **Spec / mock:** none. **Tests:** add the assertion (type LICENSED_USE, citation with own name).
- **Phase B:** none.

### B. Own copy stays OWN (owner exception, like tags/chapters)
`if (callerOwnsOriginal && original.originType === 'OWN') keep OWN, no citation`; licence still inherited.
- **Pros:** matches intuition and the existing owner exception for tags/chapters; no self-citation; your own work stays your own in listings and prints.
- **Cons:** the provenance of the copy is only visible via `originalId` (fine for the author, who is the only one who sees it); one more branch.
- **Spec:** one sentence in `copyProblem` (sketch below), and "usual copy rules" in `addSetChild` inherits it.
- **Mock:** `copy-rules.ts` gets a `callerOwnsOriginal` parameter; `problem-copies.service.ts:27` passes it (it already computes `callerOwns`).
- **Tests:** two assertions in `copy.e2e-spec.ts` and `add-child.e2e-spec.ts`.
- **Phase B:** none beyond the rule.

### C. Owner exception that depends on the licence
Own copy stays OWN only when the original has no licence or a licence allowing modification; otherwise LICENSED_USE.
- **Pros:** covers an edge case: the owner may have taken over someone else's content as OWN by mistake.
- **Cons:** harder to explain and to test; the edge case is a data-quality problem, not a copy rule.
- **Spec / mock / tests:** like B, plus a licence lookup in the rule.

## Sketch (option B, not applied to the spec)

```yaml
      description: |
        …
        Source: OWN → LICENSED_USE citing the original author, except when you copy your own
        problem (then it stays OWN, without a citation); LICENSED_USE and FREE_USE keep their type and
        citation; the licence is always inherited.
```
